# Identidade Junta

O símbolo reúne dois traços de J: uma intenção individual que encontra força no grupo. Azul #2549eb, coral #ff775e e wordmark marinho #172344. O nome usa Outfit Bold com letras convertidas em curvas: a logo não depende do carregamento de fontes.

- `junta-logo.svg`: assinatura horizontal, fundo transparente.
- `junta-symbol.svg`: símbolo para espaços pequenos e ícones.
- `node scripts/generate-assets.mjs`: replica os SVGs nos três portais e prepara os PNGs do mobile, favicon e splash.

O desenho do símbolo é original deste projeto. A tipografia Outfit é de [Outfit](https://fonts.google.com/specimen/Outfit). Não distorcer a proporção nem aplicar efeitos sobre a assinatura.
